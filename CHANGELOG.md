# Unreleased

## New Features

+ Allows specification of custom PSD files for each interferometer in the configuration file. PSDs can be provided as two-column text files (frequency, PSD value) and will be used instead of computing PSDs from the data. This enables comparable tests with other codes like Bilby and the use of on-source PSDs generated by tools like BayesWave.

## Breaking changes

This release is not believed to introduce any backwards-incompatible changes.
